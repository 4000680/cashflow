# Бюджет — Telegram-бот и Mini App

Прототип универсального финансового помощника для личного, семейного и рабочего учёта. Интерфейс поддерживает быстрый ввод нескольких операций и сохраняет их локально на устройстве. Облачная синхронизация, Telegram-бот и импорт банковских выписок подключаются отдельным этапом через Cloudflare D1, R2 и webhook.

## Что уже сделано

- мобильный интерфейс в стиле liquid glass для Telegram Mini App с белой и чёрной темой;
- разделы «Все», «Работа», «Семья», «Личное» и «Автомобиль»;
- круговая аналитика расходов, отдельные показатели дохода, расходов и прибыли;
- быстрый разбор фраз вида `1500 кофе, 300 булочка, 2500 заправка`;
- единый плюс для текстового, голосового и файлового ввода;
- прототип Telegram-клавиатуры и подтверждения распознанных голосовых операций;
- очередь проверки переводов и возможных дублей перед записью;
- единый денежный контур: прибыль работы автоматически становится доступной для личных, семейных и автомобильных расходов без повторного учёта как дохода;
- отдельные фильтры «Работа», «Семья», «Личное» и «Автомобиль»;
- изменяемые банки: Сбер, Альфа-Банк, Т-Банк;
- изменяемое ежедневное напоминание (стартовое значение — 22:30, Europe/Moscow);
- экран ручной и почтовой загрузки выписок;
- модель D1 для пользователей, счетов, операций, импортов, категорий и напоминаний;
- R2-загрузка предусмотрена для исходных файлов выписок.

## Встроенный справочник категорий

В приложении есть полный каталог личных, семейных и рабочих доходов, расходов и переводов. Он хранится в коде и работает без нейросети: каждой категории назначены ключевые слова и варианты формулировок. Пользовательские правила по тексту операции имеют приоритет над общим справочником.

«Самообучение» без нейросети реализуется как обычное правило: после ответа пользователя бот запоминает связь «текст/торговая точка → категория» в `user_recognition_rules`. При следующей похожей операции сначала применяется личное правило, затем встроенный словарь и только потом категория банка.

Каталог включает еду, дом, автомобиль, транспорт, здоровье, детей, покупки, связь, финансовые платежи, личные расходы, досуг, семью, регулярные и дополнительные доходы, доходы бизнеса, команду, налоги, рекламу, офис, сервисы, подрядчиков, оборудование, закупки, логистику, клиентские расходы, документы и все основные виды переводов.

### Что показывается на экране

- новая категория из каталога изначально скрыта;
- после первой операции она активируется автоматически;
- активная категория остаётся в отчёте в следующих месяцах, даже если её сумма равна нулю;
- пользователь может вручную включить, закрепить или скрыть категорию;
- скрытие не удаляет старые операции и не портит отчёты;
- группа показывается только тогда, когда внутри неё есть хотя бы одна активная категория.

Расходы на детей учитываются в общей группе «Дети»: школа и обучение, кружки и спорт, няня и присмотр, карманные деньги. Разделения по именам детей по умолчанию нет. При необходимости его можно добавить позже как необязательную настройку.

## Целевая архитектура

1. Telegram Bot принимает текст, документы и команды, а Mini App даёт обзор, настройки и ручную проверку.
2. Все входы приводятся к единой `TransactionCandidate`: дата, сумма в копейках, валюта, продавец, назначение, счёт, источник и внешний идентификатор.
3. Парсеры подключаются через реестр адаптеров. Первая очередь: Сбер PDF/CSV, Альфа CSV/XLSX, Т-Банк CSV/XLSX/OFX.
4. Файлы сохраняются в приватном R2 только на время обработки; метаданные и операции — в D1.
5. Перед записью выполняются нормализация, категоризация, поиск дублей и распознавание переводов.
6. Неоднозначные операции попадают в очередь подтверждения Telegram/Mini App.
7. Cron Worker отправляет напоминания в локальное время пользователя.

## Правила сверки

Точный дубль определяется по внешнему ID банка либо стабильному отпечатку нормализованных полей. Возможное совпадение оценивается по сумме, валюте, близости даты/времени, нормализованному продавцу и счёту. Ручная запись и строка выписки не объединяются автоматически при слабом совпадении.

Для пары «списание со своего счёта → зачисление на другой свой счёт» создаётся общий `transferGroup`; такие движения не считаются доходом и расходом. Неизвестные переводы задают пользователю короткий вопрос: свой счёт, другому человеку, доход или расход.

## Правила распознавания

Публичный справочник содержит только общие категории и нейтральные формулировки. Названия торговых точек из пользовательских выписок, суммы, даты, номера карт и счетов, а также имена людей в исходный код не переносятся. Индивидуальные правила распознавания сохраняются в закрытой базе конкретного пользователя.

## Автоматическая почта

Каждый пользователь получает случайный адрес импорта. Входящий Email Worker проверяет получателя и тип вложения, вычисляет контрольную сумму, кладёт файл в приватное хранилище и создаёт задание разбора. Пользователь может пересылать письма вручную или создать фильтр в своей почте. Наличие автоматической регулярной отправки выписки нужно проверять отдельно в актуальном приложении каждого банка.

## Безопасность

- токен Telegram и секрет проверки `initData` хранятся только в secrets;
- исходные выписки не отправляются в LLM; базовый парсинг выполняется локальным кодом;
- для необязательной AI-категоризации передаются только обезличенные описание и сумма;
- файлы ограничиваются по типу, размеру и сроку хранения;
- все запросы из Mini App проверяют Telegram `initData` и принадлежность записей пользователю;
- импорт идемпотентен по checksum, банковскому ID и fingerprint.

## Найденные основы, которые можно переиспользовать

- [CashFlow](https://github.com/azizmac/CashFlow) — сильная модель Сбер/Т-Банк, профилей и дедупликации, но тяжёлый .NET-стек.
- [sber_statement](https://github.com/tarovik/sber_statement) — компактный MIT-парсер PDF Сбера на Python.
- [budget-tg-manager-app](https://github.com/maximfersko/budget-tg-manager-app) — примеры CSV-полей Т-Банка и Альфа-Банка.
- [ebk-bank-helper](https://github.com/streletskiy/ebk-bank-helper) — идеи сопоставления T-Банк CSV/XLSX/OFX.
- [actual-budget-telegram-bot](https://github.com/bbharathbala/actual-budget-telegram-bot) — полезные Telegram-сценарии, семьи и напоминаний.

Код из проектов без явной лицензии в продукт не переносится. Перед заимствованием каждый модуль проверяется по лицензии, тестам и свежим реальным выпискам.

## Следующий этап разработки

1. Создать отдельного бота через BotFather и настроить Web App URL.
2. Подключить D1, R2, webhook Telegram и проверку `initData`.
3. Реализовать быстрый текстовый ввод и CRUD операций.
4. Добавить Сбер как первый production-парсер на обезличенных примерах.
5. Добавить сверку дублей и переводов, затем Альфа-Банк и Т-Банк.
6. Подключить Email Worker и Telegram-напоминания.
